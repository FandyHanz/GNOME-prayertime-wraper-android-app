## 📖 English Version

### About the Project
This project brings the clean, minimalist, and reliable experience of the desktop **GNOME Shell Extension: Prayer Times** into an accessible mobile app. Built with Flutter using an **MVC architecture**, it focuses on efficiency, low resource consumption, and seamless utility across all Android devices, including entry-level hardware.

> **Credits & Attribution:**  
> Rebuilt by **Fandy Hanz**.  
> Based on the original desktop extension by **[Mocab](https://github.com/Mocab/Prayer-times-gnome-extension)**.  
> Core prayer calculations powered by the algorithms from **[PrayTimes.org](https://praytimes.org)** (by Hamid Zarrabi-Zadeh).

---

### ✨ Key Features
* **Status Bar Ongoing Notification:** A pinned, silent status bar tracker showing countdowns and the next prayer schedule at a glance.
* **Timely Alerts:** Heads-up notifications trigger precisely when prayer time arrives.
* **Built-in Qibla Compass:** Smooth, real-time compass heading directly pointing to the Kaaba coordinates ($21.4225^\circ \text{ N}, 39.8262^\circ \text{ E}$).
* **GPS & Manual Positioning:** One-tap GPS auto-detection with full support for manual coordinates and custom calculation angles (Fajr/Isha).
* **Adwaita Dark Theme:** Native GNOME desktop aesthetic tailored for mobile screens.
* **Broad Device Support:** Optimized for low RAM usage, compiled for both 32-bit (`armeabi-v7a`) and 64-bit (`arm64-v8a`) architectures.

## 🇮🇩 Versi Bahasa Indonesia

### Tentang Proyek
Proyek ini mengadaptasi fungsionalitas dan estetika minimalis dari **GNOME Shell Extension: Prayer Times** menjadi aplikasi Android mandiri menggunakan Flutter dengan pola arsitektur **MVC**. Aplikasi ini dirancang agar ringan, hemat baterai, bebas iklan, dan ramah untuk semua jenis spesifikasi perangkat.

> **Atribusi & Kredit:**  
> Dikembangkan ulang oleh **Fandy Hanz**.  
> Diadaptasi dari ekstensi orisinal karya **[Mocab](https://github.com/Mocab/Prayer-times-gnome-extension)**.  
> Perhitungan astronomi jadwal salat menggunakan basis algoritma dari **[PrayTimes.org](https://praytimes.org)** oleh Hamid Zarrabi-Zadeh.

---

### ✨ Fitur Utama
* **Notifikasi Status Menetap (Ongoing):** Menampilkan sisa waktu dan jadwal salat berikutnya di status bar secara terus-menerus tanpa mengganggu.
* **Pengingat Waktu Masuk Salat:** Banner notifikasi otomatis muncul tepat saat waktu salat tiba.
* **Kompas Arah Kiblat:** Menghitung derajat arah Ka'bah secara real-time berdasarkan posisi lintang dan bujur pengguna.
* **Dukungan Lokasi Fleksibel:** Deteksi otomatis menggunakan GPS maupun penyesuaian manual (koordinat, sudut fajar/isya, dan metode bayangan Asar).
* **Tampilan Khas GNOME Dark:** Palet warna gelap modern yang nyaman di mata dan hemat daya layar AMOLED.
* **Performa Ringan:** Ukuran aplikasi kecil serta kompatibel untuk ponsel spesifikasi standar (tersedia build 32-bit dan 64-bit).
